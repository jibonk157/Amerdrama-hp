AMERDRAMA Android v1 - Proyek sumber (BUKAN APK)

1. Buka folder proyek ini di Android Studio.
2. Tunggu Gradle Sync selesai (perlu internet untuk dependency Android).
3. Pilih Build > Build Bundle(s) / APK(s) > Build APK(s).
4. Hasil debug APK: app/build/outputs/apk/debug/app-debug.apk
5. Pindahkan APK ke HP Android dan instal.

Prototipe WebView lokal: pencarian, kategori, favorit, pemutar video demo.
Video demo membutuhkan internet. Belum ada backend, login, upload, iklan atau episode asli.
